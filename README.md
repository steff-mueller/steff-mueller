Some of my open-source history:

- **[ServiceStack](https://github.com/ServiceStack/ServiceStack/commits?author=steff-mueller)** (5k+ stars, 2011–2013):
  past core contributor to this .NET web services framework. Built request validation,
  role- and permission-based authorization, and request/response filters.
- **[supertest](https://github.com/forwardemail/supertest/pull/54)** (14k stars, 2013):
  added `request.agent(app)` for testing sessions that persist cookies across requests.
- **[react-virtualized](https://github.com/bvaughn/react-virtualized/pull/124#issuecomment-6252253739)** (27k stars, 2016):
  found that every visible row re-rendered on every scroll and proposed stable cell keys.
  The maintainer is adopting the approach for v10.
- **[pyMOR](https://github.com/pymor/pymor/pulls?q=author%3Asteff-mueller)** (2023):
  contributed a spectral factorization method and a
  [port-Hamiltonian tutorial](https://docs.pymor.org/2025-2-2/tutorial_ph.html)
  to this Python library for model order reduction.
